# 📊 Kurikulum Data Science Profesional

Kurikulum ini dirancang secara komprehensif untuk mempersiapkan peserta menjadi **Data Scientist** yang siap kerja di industri, mulai dari penguasaan fondasi pemrograman hingga *deployment* model ke produksi.

---

## 🎯 Target Kompetensi Lulusan
Setelah menyelesaikan seluruh modul, peserta mampu:
* Mengolah, membersihkan, dan menganalisis dataset skala besar secara efisien.
* Membangun model *Machine Learning* dan *Deep Learning* untuk menyelesaikan masalah bisnis.
* Mengomunikasikan *insight* data melalui visualisasi yang efektif dan berbasis cerita (*data storytelling*).
* Melakukan *deployment* model ke lingkungan produksi dengan standar MLOps dasar.

---

## 🗓️ Struktur Modul Pembelajaran

| Fase | Fokus Utama | Estimasi Durasi | Output / Deliverable |
| :--- | :--- | :--- | :--- |
| **Fase 1** | Fondasi Pemrograman & Data | 3 Minggu | Skrip Analisis Data & Kueri SQL |

## 📚 Silabus Detail per Fase

### Fase 1: Fondasi Pemrograman & Manipulasi Data
Fokus pada penguasaan alat kerja utama yang digunakan sehari-hari oleh Data Scientist.
* **Python untuk Data Science:** Struktur data, fungsi, OOP dasar, dan pengelolaan *environment* (`venv` / `conda`).
* **Manipulasi Data:** Komputasi numerik dengan **NumPy** serta pembersihan dan transformasi data tabular menggunakan **Pandas** atau **Polars**.
* **Database & SQL:** Kueri kompleks (`JOIN`, *Subqueries*, *Window Functions*, CTE) untuk ekstraksi data dari *relational database*.
* **Version Control:** Kolaborasi kode menggunakan **Git** dan **GitHub**.

### Fase 2: Matematika, Statistik & Eksplorasi Data (EDA)
Membangun intuisi analitis sebelum masuk ke pemodelan algoritmik.
* **Statistik Deskriptif & Inferensial:** Distribusi probabilitas, uji hipotesis (*A/B Testing*), *p-value*, dan korelasi.
* **Aljabar Linear & Kalkulus Dasar:** Pemahaman matriks, vektor, dan konsep gradien di balik algoritma ML.
* **Exploratory Data Analysis (EDA):** Penanganan *missing values*, *outliers*, dan deteksi anomali data.
* **Visualisasi Data:** Membuat grafik informatif dengan **Matplotlib**, **Seaborn**, dan *dashboard* interaktif (**Plotly** / **Streamlit**).

### Fase 3: *Machine Learning* Terapan
Mempelajari algoritma klasik hingga *ensemble* untuk kasus regresi, klasifikasi, dan klastering.
* **Feature Engineering & Preprocessing:** *Encoding*, *scaling*, seleksi fitur, dan penanganan *imbalanced dataset* (SMOTE).
* **Supervised Learning:** Linear/Logistic Regression, Decision Trees, Random Forest, serta Gradient Boosting (**XGBoost**, **LightGBM**, **CatBoost**).
* **Unsupervised Learning:** K-Means, DBSCAN, Hierarchical Clustering, dan reduksi dimensi (PCA).
* **Evaluasi & Tuning:** *Cross-validation*, *hyperparameter tuning* (Optuna/GridSearch), serta pemilihan metrik bisnis (Precision, Recall, F1-Score, ROC-AUC, RMSE).

### Fase 4: *Deep Learning* & Pengenalan GenAI
Menangani data tidak terstruktur seperti teks, gambar, dan deret waktu kompleks.
* **Neural Networks Dasar:** Arsitektur ANN, fungsi aktivasi, *backpropagation* menggunakan **PyTorch** atau **TensorFlow**.
* **Computer Vision / NLP Dasar:** Pengenalan CNN untuk klasifikasi gambar serta pemrosesan teks modern (*Embeddings* & *Transformers*).
* **Integrasi LLM:** Pemanfaatan *Large Language Models* dan konsep dasar *Retrieval-Augmented Generation* (RAG) untuk analisis dokumen.

### Fase 5: MLOps, *Deployment* & *Capstone Project*
Menjembatani model dari *notebook* eksperimen menjadi produk yang dapat diakses pengguna.
* **Packaging & API:** Membungkus model menjadi REST API menggunakan **FastAPI**.
* **Containerization:** Membuat *image* aplikasi yang portabel dengan **Docker**.
* **Experiment Tracking:** Mencatat parameter dan performa eksperimen menggunakan **MLflow**.
* **Capstone Project (End-to-End):**
  1. Merumuskan masalah bisnis nyata dan mengumpulkan dataset.
  2. Melakukan pembersihan data, EDA, dan pemodelan.
  3. Melakukan *deployment* model ke cloud dan menyusun dokumentasi lengkap di GitHub.
