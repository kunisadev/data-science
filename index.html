Sebelum menyentuh algoritma, seorang Data Scientist wajib memahami bagaimana ketidakpastian diukur dan bagaimana menarik kesimpulan yang sah dari sampel terbatas.
  • Ukuran pemusatan dan ketahanan (robustness): Mean, Median, Trimmed Mean, serta kondisi kapan masing-masing wajib digunakan.
  • Ukuran sebaran dan bentuk kurva: Variance, Standard Deviation, Interquartile Range (IQR), Median Absolute Deviation (MAD), Coefficient of Variation (CV), Skewness, dan Kurtosis.
  • Distribusi probabilitas fundamental: Normal (Gaussian), Binomial, Poisson, Eksponensial, Student's t, dan Chi-Square, serta Central Limit Theorem (CLT).
  • Logika pengujian hipotesis: Hipotesis Nol (H0) vs Alternatif (H1), p-value, Confidence Interval, Kesalahan Tipe I (α), Kesalahan Tipe II (β), dan Statistical Power (perhitungan ukuran sampel minimum).
  • Uji Parametrik vs Non-Parametrik: Uji normalitas (Shapiro-Wilk, Kolmogorov-Smirnov), t-test (independen & berpasangan), ANOVA, Mann-Whitney U, Wilcoxon Signed-Rank, dan Kruskal-Wallis.
  • Analisis hubungan dan asosiasi: Korelasi Pearson vs Spearman, Covariance, serta uji Chi-Square (χ²) untuk tabel kontingensi kategorikal.
  • Vektor, matriks, perkalian dot product, eigenvalues/eigenvectors (fondasi reduksi dimensi PCA), serta konsep turunan parsial dan gradient descent (fondasi optimasi fungsi kerugian / loss function).
Menurut Wes McKinney dan standar CRISP-DM, 60%–70% waktu kerja riil dihabiskan pada tahap pengumpulan, integrasi, dan pembersihan data.
  • Struktur data inti (list, tuple, set, dict), komprehensi (list/dict comprehensions), fungsi modular (def), exception handling (try-except), serta penulisan kode bersih berstandar PEP 8.
  • NumPy & Vectorization: Arsitektur n-dimensional array (ndarray), broadcasting, dan penghindaran iterasi loop manual untuk efisiensi komputasi.
  • Indexing dan seleksi tingkat lanjut (Boolean indexing, .loc, .iloc, MultiIndex).
  • Transformasi relasional: groupby dengan agregasi kustom (.agg()), penggabungan tabel (merge, join, concat), serta perubahan bentuk (reshaping dengan pivot_table, melt, stack/unstack).
  • Protokol audit kualitas data: Penanganan missing values (membedakan mekanisme MCAR, MAR, MNAR), deteksi duplikat, standardisasi teks (Regular Expressions / regex), parsing waktu (datetime), dan deteksi anomali multivariat/berkelompok.
  • Kueri relasional kompleks (INNER, LEFT, FULL OUTER, SELF JOIN), subqueries, dan Common Table Expressions (CTE).
  • Window Functions untuk analitik lanjutan: ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), LEAD(), serta kalkulasi agregasi bergerak (running totals dan moving averages).
Berdasarkan filosofi John Tukey (EDA sebagai kerja detektif data), Cole Nussbaumer Knaflic (Storytelling with Data), dan Hadley Wickham (Layered Grammar of Graphics).
  • Analisis Univariat (memeriksa multimodalitas, ekor distribusi, dan granularity data), Bivariat (hubungan non-linear, efek Simpson's Paradox), dan Multivariat.
  • Strategi identifikasi dan perlakuan outlier: Membedakan measurement error dari natural extreme values, serta teknik transformasi (log transform, Box-Cox, Yeo-Johnson, atau winsorizing).
  • Penguasaan pustaka Matplotlib (anatomi Figure dan Axes) dan Seaborn (Histogram + KDE, Boxplot, Violin Plot, Jointplot, Pairplot, Clustered Heatmap).
  • Pemilihan jenis grafik berdasarkan tujuan kognitif (perbandingan, komposisi, distribusi, hubungan).
  • Penghapusan chartjunk (Edward Tufte), penerapan pre-attentive attributes (warna fokus, hierarki tipografi), dan penyusunan narasi temuan untuk pemangku kepentingan non-teknis.
Merujuk pada ISLR dan Hands-On Machine Learning—memahami keseimbangan Bias-Variance Tradeoff dan pencegahan kebocoran data (data leakage).
  • Pembagian data yang sah: Train/Validation/Test split, Stratified Split, dan Group Split (agar entitas yang sama tidak bocor antara data latih dan uji).
  • Pembungkusan transformasi menggunakan Scikit-Learn Pipeline dan ColumnTransformer: Imputation (SimpleImputer, KNNImputer), Scaling (StandardScaler, MinMaxScaler, RobustScaler), dan Encoding (OneHotEncoder, OrdinalEncoder, TargetEncoder).
  • Seleksi fitur: Filter methods (korelasi, mutual information), Wrapper methods (RFE), dan Embedded methods (penalti Lasso L1).
  • Ordinary Least Squares (OLS) beserta uji asumsi klasiknya (linearitas, homoskedastisitas, multikolinearitas/VIF).
  • Regularisasi untuk mencegah overfitting: Ridge Regression (L2), Lasso Regression (L1), dan ElasticNet.
  • Regresi non-linear berbasis pohon: Decision Tree Regressor, Random Forest, dan Gradient Boosted Decision Trees (XGBoost, LightGBM, CatBoost).
  • Logistic Regression (logika log-odds dan fungsi sigmoid), Support Vector Machines (SVM), Random Forest, dan XGBoost/LightGBM.
  • Penanganan Imbalanced Dataset: Class weighting, oversampling (SMOTE), undersampling, serta kalibrasi probabilitas (Platt Scaling / Isotonic Regression).
  • K-Fold Cross-Validation dan Stratified K-Fold.
  • Pemilihan metrik sesuai biaya kesalahan bisnis: Regresi (MAE, RMSE, MAPE, R²); Klasifikasi (Confusion Matrix, Precision, Recall, F1-Score, ROC-AUC, Precision-Recall AUC, serta optimalisasi decision threshold).
  • Pencarian hyperparameter: GridSearchCV, RandomizedSearchCV, dan optimasi Bayesian (Optuna).
Memperluas kapabilitas analitik pada data tanpa label, data berdimensi waktu/ruang, serta pembuktian hubungan sebab-akibat.
  • Algoritma pengelompokan: K-Means, K-Prototype (khusus data campuran numerik dan kategorikal), Hierarchical Clustering (Agglomerative), dan DBSCAN (berbasis kepadatan untuk menangkap bentuk klaster non-bulat serta memisahkan noise).
  • Validasi klaster: Elbow Method, Silhouette Score, Davies-Bouldin Index, serta validasi eksternal menggunakan uji statistik antar-klaster.
  • Reduksi dimensi: Principal Component Analysis (PCA) dan visualisasi manifold (t-SNE, UMAP).
  • Dekomposisi komponen (Trend, Seasonality, Residual), uji stasioneritas (Augmented Dickey-Fuller), dan analisis autokorelasi (ACF & PACF).
  • Pemodelan: Exponential Smoothing (Holt-Winters), ARIMA/SARIMA, Prophet, dan pendekatan regresi ML berbasis fitur lag dengan skema validasi TimeSeriesSplit (mencegah kebocoran masa depan).
  • Sistem koordinat referensi (CRS / proyeksi peta), operasi spasial (spatial join, buffer, overlay), dan pemetaan tematik (Choropleth Map).
  • Perbedaan fundamental antara korelasi prediktif dan kausalitas intervensi (Pearl's Ladder of Causation).
  • Desain eksperimen terkontrol (Randomized Controlled Trials / A/B Testing) serta metode kuasi-eksperimental untuk data observasional: Propensity Score Matching (PSM) dan Difference-in-Differences (DiD).
Berdasarkan kerangka Chip Huyen dan Christoph Molnar—memastikan model transparan, dapat direproduksi, dan bertahan di lingkungan nyata.
  • Interpretasi global vs lokal: Permutation Feature Importance, Partial Dependence Plots (PDP), dan nilai SHAP (SHapley Additive exPlanations) untuk menjelaskan kontribusi setiap fitur pada prediksi individual.
  • Audit keadilan model (Fairness & Bias Detection) untuk mencegah diskriminasi antar-subkelompok populasi.
  • Manajemen versi kode dengan Git & GitHub, struktur direktori standar proyek (Cookiecutter Data Science), manajemen lingkungan virtual (venv/conda), dan pengelolaan dependensi (requirements.txt).
  • Pengujian otomatis (Unit Testing dengan pytest untuk memvalidasi fungsi transformasi data).
  • Serialisasi model (joblib / ONNX) dan penyajian model sebagai antarmuka interaktif (Streamlit / Gradio) atau layanan API (FastAPI).
  • Pemantauan pasca-produksi: Deteksi pergeseran distribusi data (Data Drift menggunakan Population Stability Index / PSI atau uji Kolmogorov-Smirnov) serta penurunan performa model (Concept Drift).

01

Diagnosa Sebaran Data (Skewness & Modality)

A. Membandingkan Mean vs Median

Membandingkan nilai rata-rata (Mean) dan nilai tengah (Median) adalah cara tercepat untuk mendeteksi ketidakseimbangan bentuk distribusi data sebelum membuat grafik.

Kondisi Metrik Bentuk Kurva Visual Ekor Makna & Penyebab di Lapangan
Mean ≈ Median Simetris (Normal) Data tersebar merata di sekitar pusat; tidak ada nilai ekstrem yang menarik rata-rata.
Mean > Median Right-Skewed Ekor melandai panjang ke kanan karena ada segelintir nilai ekstrem besar yang menarik rata-rata naik.
Mean < Median Left-Skewed Ekor melandai panjang ke kiri akibat adanya nilai ekstrem sangat kecil yang menarik rata-rata turun.

B. Pasangan Metrik yang Wajib Konsisten

Satu angka pusat wajib didampingi pasangan sebaran dari keluarga rumus yang sama agar kondisi lapangan terlihat utuh dan tidak menipu:

Keluarga Parametrik (Simetris)
Mean + Standar Deviasi (std)

Standar Deviasi (std) adalah akar kuadrat dari Varians. Dipakai saat distribusi data simetris dan bersih dari anomali ekstrem.

Keluarga Non-Parametrik (Miring / Outlier)
Median + IQR (Q3 - Q1)

Interquartile Range (IQR) mengukur rentang 50% data tengah. Dipakai saat data miring (skewed) atau ber-outlier.

Kasus Dua Desa Beromzet Sama: Dua desa bisa memiliki rata-rata omzet yang sama persis, tetapi Desa A merata di seluruh warga (std & IQR kecil), sedangkan Desa B dikuasai satu orang kaya raya dan sisanya miskin (std & IQR timpang). Tanpa metrik sebaran, angka pusat saja akan menipu!

C. Covarians vs Korelasi & Kurva Miring 2 Puncak (Skewed Bimodal)

Covarians vs Korelasi (.corr())

Covarians hanya melihat arah hubungan 2 variabel (+ searah, - berlawanan) tanpa batas skala, sedangkan Korelasi (.corr()) menormalisasinya ke skala baku -1 hingga +1 untuk mengukur kekuatan hubungan.

Kurva Miring 2 Puncak (Skewed Bimodal)

Jika kurva punya 2 puncak, artinya dua populasi berbeda sedang tercampur. Wajib dipisah dulu dengan .groupby() sebelum dihitung agar tidak menghasilkan "rata-rata hantu" di lembah kosong.

B. Alur Hitung Manual IQR & Pagar Anomali (Studi Kasus 15 Antrean)

  1. Urutkan data dan cari posisi Q1 (25%), Median (50%), dan Q3 (75%).
  2. Hitung rentang tengah: IQR = Q3 - Q1.
  3. Hitung pagar batas atas: Batas Atas = Q3 + (1.5 × IQR). Nilai di luar pagar ini sah berstatus outlier (yang membentuk ekor panjang pada kurva dan titik bintang di luar kumis Boxplot).

C. Aturan Penanganan Anomali

Kesalahan Input / Teknis (Error)
Hapus (drop) atau Koreksi

Jangan asal menghapus (drop) outlier. Hapus/koreksi hanya jika terbukti kesalahan input/teknis (error).

Fakta Nyata (True Outlier)
Pertahankan & Uji Metode Alternatif

Jika merupakan fakta nyata (true outlier), pertahankan datanya dan gunakan uji non-parametrik, transformasi logaritma (np.log()), atau lakukan uji dua kali (dengan dan tanpa anomali).

C. Boolean Indexing & Fungsi (def)

Boolean Indexing (df[df['kolom'] > batas]) menggunakan hasil perbandingan True/False (dieksekusi serentak via vectorization tanpa for loop) sebagai penyaring baris tabel secara utuh. Sementara Fungsi (def) membungkus rumus dan logika for/if menjadi mesin otomatis yang bisa dipanggil ulang, mengembalikan hasil lewat return, dan menyimpannya ke variabel penerima di sebelah kiri tanda =.

python — colab_deteksi_outlier_dan_pandas.py 
import pandas as pd
import numpy as np

# 1. Fungsi otomatis (def) untuk deteksi outlier atas pada data_list
def deteksi_outlier_atas(data_list):
    seri = pd.Series(data_list)
    q1 = seri.quantile(0.25)
    q3 = seri.quantile(0.75)
    iqr = q3 - q1
    batas_atas = q3 + (1.5 * iqr)

    outlier_list = []
    for nilai in data_list:
        if nilai > batas_atas:
            outlier_list.append(nilai)

    return batas_atas, outlier_list

# Uji fungsi dengan studi kasus 15 antrean:
data_antrean = [4, 5, 6, 6, 7, 7, 8, 8, 9, 9, 10, 11, 12, 24, 38]
batas, anomali = deteksi_outlier_atas(data_antrean)
print("Batas Atas:", batas, "| Outlier:", anomali)

# 2. Contoh Pandas: Pisahkan populasi bimodal (.groupby) & Boolean Indexing
df = pd.DataFrame({'shift': ['Pagi']*8 + ['Sore']*7, 'antrean': data_antrean})
ringkasan_shift = df.groupby('shift')['antrean'].agg(['mean', 'median', 'std'])
df_outlier = df[df['antrean'] > batas]
